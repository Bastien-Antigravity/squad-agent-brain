# 🚀 Features & Behavior: base-scripts

## Key Capabilities

1. **Autonomous Microservice Scaffolding (`scaffold-microservice`)**:
   Generates production-ready Go, Python, or Rust microservice directories complete with the 12+ mandatory root files, Docker composition, BDD spec stubs, and registration snippets.

2. **4-Layer Port Drift Verification (`audit-ports`)**:
   Guarantees zero port collisions or schema desynchronization across the entire ecosystem.

3. **Mechanical Invariant Enforcement (`validate-compliance`)**:
   Verifies AST compliance across Go, Python, Rust, and C++ code.

4. **Multi-Channel Squad Dashboard**:
   Provides real-time AI squad coordination over OpenMFE Web UI, Telegram, and Discord with session persistence in PostgreSQL.
